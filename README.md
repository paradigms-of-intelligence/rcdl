# Retrieval-centric deep learning

The notebooks (JAX/PyTorch) in this repository contain the implementations of main algorithms and baselines presented in the paper "Retrieval-Centric Deep Learning in Growing Nonparametric Neural Networks" and reproduce the 1-epoch training run on CIFAR-10 experiment presented in Figure 2.
